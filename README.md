# Kur'an-ı Kerim – Android (Galaxy Z Fold 7)

Kitap görünümlü Kur'an uygulaması: solda meal veya tefsir, sağda mushaf sayfası (604 sayfa).

- APK: `apk/Kuran-Kerim.apk` (her derlemede GitHub Actions tarafından güncellenir)
- Veri ve yazı tipleri derleme sırasında `tools/prepare_data.py` ile indirilir.
